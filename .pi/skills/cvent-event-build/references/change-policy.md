# Policy authority and technical boundaries

[SKILL.md](../SKILL.md) is the final client business policy. It defines the included
tabs, row filters, defaults, source precedence, leftover preservation, configuration
order and configuration-only acceptance. Do not reinstate older business rules from
historical reports, removed references or another workbook. The original workbook
remains unchanged; record each policy-derived value separately from its source.

The skill does not override tool restrictions, runtime guards, browser ownership or
supported login handoff. A denial is not permission to change transport, clear a
marker, alter a lock or create another browser/session. Follow [runner integration](runner-integration.md)
and the assigned [Steel bridge](browser/references/steel-bridge.md).

## Protected scope

Use only the bound job's workbook/version and authorizedEvent. Confirm event ID/name
and unpublished state; do not change its title or ID, publish, submit registrations,
send email, or edit shared/account definitions, venues, templates or other events.
There is no shared-contact-type creation exception in this build, even if a broader
tool capability exists. Reuse existing definitions and configure only this event's
supported assignments. A missing shared definition is an unfinished dependency.

Leave last year's objects absent from the doc alone. A requested included change
still requires an actually supported event-local operation. The installed discount
adapter can replace explicit item associations under its baseline/readback rules;
this is not whole-object deletion. Whole-question, answer-choice and whole-discount
deletion are not made executable by this policy. Do not probe or bypass deletion
guards. Record the affected item and continue independent work.

## Changes and outcomes

Apply the skill's authorized defaults and judgment calls rather than demanding a
workbook correction for them. Record original values, the exact governing rule and
the chosen result. Unsupported required values/operations remain Not done, not a
reason to fabricate successful execution or silently broaden eligibility.

A concurrent-editor banner alone does not withhold a permitted Save under the
approved policy. Record each such save, baseline, outcome and evidence; do not claim
that readback proves another editor's work was preserved. This does not authorize
shared-template changes, overriding an actual lock or any operation denied by tools.

Keep intended writes separate from independently read-back saved changes. Known
pre-write failures affect their dependent items. Possible changes with an unknown
outcome, loss of identity/ownership, exposed secrets, operator Stop and executable
safety stops retain their existing protections. No automatic stopped-session resume.

DONE covers saved configuration under the approved rules, with registration testing
not performed. INCOMPLETE covers any included unfinished configuration. STOPPED
covers interruption under the skill or runtime. Exclusions receive no completion
credit. Follow [runner contract](runner-contract.md); do not rewrite old evidence.
