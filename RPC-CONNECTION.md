## Endpoints

All are local-only and require no app credentials. Upload uses multipart field `rr`; other POST bodies are JSON.

- `POST /api/jobs` — save an original RR, prepare a fresh empty native session, return job ID/workspace/hash/session ID. No model prompt.
- `POST /api/jobs/:id/continue` — disabled (409); upload for a fresh run.
- `GET /api/jobs/:id` — durable job ledger.
- `POST /api/target` — `{eventName}`; invalidates the old target lock and performs exact-name Cvent API search. Returns one unique `apiEvent`. Human login and `POST /api/return-agent` confirm the same event in Steel.
- `POST /api/jobs/:id/start` — `{authorizedEventName}` only; scope and spending overrides are rejected. The runner snapshots its fixed scope and internal spending policy into the durable job before prompting Pi; the name must match the previously confirmed target. API and browser preflight must both pass before any paid prompt; the API event UUID and browser identity are persisted, not guessed from the name.
- `POST /api/jobs/:id/rpc` — native `get_state`, `get_session_stats`, `get_last_assistant_text`, `get_commands`, `steer` or `follow_up`. Queue messages require bounded plain text `message`, not slash commands. Reset, model changes, arbitrary shell RPC and ungated prompts are not exposed. Extension UI dialogs appear in the event stream but interactive extension-dialog responses are not yet exposed; stop and resolve such blockers rather than leaving paid execution unattended.
- `GET /api/jobs/:id/events` — live SSE with sequence IDs. Reconnection is live-only; durable full history is available as `progress.jsonl`, so disconnects do not lose evidence.
- `GET /api/jobs/:id/results/:file` — allowlisted `job.json`, `state.json`, `progress.jsonl`, `result.json`, `final-report.json`, `final-report.md`. Missing artifacts return 404, not fabricated success. Section receipts and native sessions also remain in the private workspace.
- `POST /api/jobs/:id/stop` — revoke job browser control, acknowledge `clear_queue`, then native `abort` and `abort_bash`, snapshot costs, terminate only the owned Pi process group (including its Ego programs). If queue clearing fails, terminate owned execution without unsafe native abort. The shared Steel service and human browser are not destroyed. Take Control and graceful server shutdown use this same Stop path.

## Safety and spending limits

- Stop does not undo API/UI requests already submitted. Keep receipts, progress and unresolved changes; inspect authoritative Cvent state before further work. `STOPPED_REQUIRES_REVIEW` is not rollback or completion.
- Job ledgers, sessions, reported cumulative cost (including Pi-reported tool/compaction costs), originals and evidence survive fresh context. Every new run uses a fresh upload/session; prior conversation context is never resumed. New uploads cannot hide prior execution for the same event.
- Cost controls are internal, not operator form fields. The fixed policy uses a $60 allowance and $10 external/in-flight reserve, pausing at $50 of cumulative reported Pi usage across the event's jobs to leave headroom for the under-$60 total goal. Costs are sampled every two seconds and after cancellation. This is **not an exact billing cap**: provider usage may arrive late, one request can overshoot, and external Steel/API charges are not metered here. Missing model pricing blocks prompts; lost metering pauses execution and flags reconciliation. A reported zero does not prove zero spend.
- Cvent prohibitions are execution instructions plus the existing UI guards, **not a new security sandbox**. Native Pi retains the requested shell/workbook/API capabilities. Use appropriately scoped Cvent credentials. Never delete/archive, publish events, send communications, change other events, or blindly replay uncertain writes.
- Server restart does not automatically terminate orphaned resources or reconcile provider billing. Native Pi exits on stdin EOF, but durable in-flight records still require operator review.
